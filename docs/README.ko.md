# Vernal Edge 한국어 패치 0.1.0-beta.3

**전체 번역의 1차 텍스트 재검토를 마친 사용자 검수용 베타입니다. 전 구간 플레이 검수가 끝난 정식판은 아닙니다.**

- 대상: Windows 64비트 Steam판, App ID 1546710, Build ID 10939741.
- 1,838개 고유 메시지 전체 번역. 메뉴·대사·설명·튜토리얼·일지·도전 과제·크레딧 직책 포함.
- 언어 메뉴에 독립적인 **한국어** 추가. 기존 언어는 그대로 사용할 수 있습니다.
- 본문에 한글 완성형 11,172자와 호환 자모 추가. 크레딧 별도 폰트도 번역문에 맞게 보강.
- 그림에 포함된 영문, Steam 자체 도전 과제 화면, 음성은 교체하지 않습니다.
- 고유명사·제작사·실명은 일부 원문을 유지합니다.
- beta.2 대비 164개 문구 교정. 검토 범위와 남은 확인 사항은 `FULL_REVIEW.md`를 참고하세요.

## 설치

1. 게임을 완전히 종료합니다. 폴더를 확인하려면 Steam → 게임 속성 → 설치된 파일 → 찾아보기를 사용하세요.
2. 배포 ZIP을 풀어 생성된 `VernalEdge-Korean-0.1.0-beta.3` 폴더를 게임 폴더 안에 둡니다.
3. 해당 패치 폴더에서 PowerShell을 열어 다음 명령을 실행합니다.

```powershell
.\Patch.ps1 -Mode Install -AllowBeta
```

다른 위치에 풀었다면 게임 폴더를 명시합니다.

```powershell
.\Patch.ps1 -Mode Install -AllowBeta -GameDirectory 'E:\SteamLibrary\steamapps\common\Vernal Edge'
```

4. 게임의 설정 → Language에서 **한국어**를 고릅니다.

관리자 권한이나 Python, .NET 별도 설치는 필요하지 않습니다. Windows PowerShell 5.1 이상에서 동작합니다. 시스템 정책이 스크립트 실행을 막으면 정책을 임의 변경하지 말고 관리자 또는 제작자에게 문의하세요.

설치기는 실행 파일과 대상 원본의 SHA-256을 검사합니다. 다른 버전, 이미 변조된 파일, 설치 충돌이면 적용하지 않습니다. 원본은 게임 폴더의 `.vernal-edge-ko-backup`에 보존됩니다. **이 폴더를 삭제하지 마세요.** 세이브 파일은 읽거나 수정하지 않습니다.

## 확인·제거·복구

이전 베타가 설치되어 있다면 기존 패치의 `-Mode Uninstall`을 먼저 실행한 뒤 새 버전을 설치하세요. 최초 원본 백업은 그대로 보존됩니다.

```powershell
.\Patch.ps1 -Mode Verify
.\Patch.ps1 -Mode Uninstall
```

- 확인은 현재 설치된 세 파일의 SHA-256을 검사합니다.
- 제거는 원본을 복원하고 추가된 한국어 파일을 제거합니다. 백업은 보존합니다.
- 설치가 도중에 중단되면 게임을 실행하기 전에 `-Mode Uninstall`을 실행하세요.
- 제거 시 수정 충돌이 나오면 해당 파일과 백업을 보존하세요. 사용자 수정이나 Steam 업데이트를 임의로 덮어쓰지 않습니다.
- 제거 후 게임의 언어 설정이 한국어를 가리키면 설정에서 English 등 기본 언어를 다시 골라 주세요. 패치가 저장 설정을 직접 고치지는 않습니다.
- Steam 업데이트 이후에는 지원되는 새 패치를 기다리세요. 업데이트된 파일에 옛 패치를 강제로 적용하지 마세요.

## 검수 요청

`QA.md`의 항목을 확인해 주세요. 오역·잘림·깨짐이 있으면 영어 원문 또는 한국어 문구, 지역·상황, 화면 배율, 입력 장치 종류를 함께 알려 주세요. 스토리와 수집품, 미니게임, 엔딩·크레딧은 전 구간 검수가 필요합니다.

## 배포물

`payload/*.gz`와 `manifest.json`은 원본을 참조하는 COPY/ADD 차분 형식입니다. 원본 게임 전체나 실행 파일을 포함하지 않습니다. `ko-KR.json`과 `available.json`은 확인·편집용 사본이며 실제 설치는 무결성 검사를 수행하는 설치기를 사용하세요. 사용자 게임의 원본 데이터가 있어야 패치를 재구성할 수 있습니다.

비공식 팬 번역입니다. 게임 저작물의 권리는 원저작자에게 있습니다. 폰트와 개발 도구의 출처는 `THIRD_PARTY_NOTICES.md`를 참고하세요.
