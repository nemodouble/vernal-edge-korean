## Windows PowerShell 5.1 설치기 테스트: 12개 통과

1. 정상 설치·검사·중복 설치·제거·재설치, 최초 백업 보존
2. 다른 원본 파일 거부
3. 다른 실행 파일·버전 거부
4. 사용자가 만든 기존 한국어 파일 보존
5. 손상된 페이로드 거부, 적용 전 원본 보존
6. 설치 후 사용자 수정이 있으면 전체 제거 중단
7. 손상된 원본 백업이 있으면 제거 중단
8. 일부 파일만 적용된 중단 상태에서 원본 복구
9. 두 번째 파일 교체 실패 시 첫 번째 파일까지 자동 원복
10. 게임 실행 중 변경 거부
11. 경로 이탈 대상 거부
12. 유효하지 않은 원본 COPY 범위 거부

추가로 실제 배포 패키지와 배포용 모듈을 사용해 지원 원본의 별도 사본에서 설치 → 검사 → 제거를 실행했다. 추가된 한국어 JSON은 제거되고, 원본 파일들의 SHA-256이 모두 처음과 같았다. 기록은 `private/build/package-smoke.json`에 보존한다.

## 사용자 확인 및 남은 관문

사용자가 최초 시제품에서 독립 한국어 선택·한글 표시·재실행 후 유지가 모두 정상임을 확인했다.

전체 번역 베타는 전 구간 플레이, 기존 세이브, 컨트롤러, 배율, 긴 대사와 엔딩·크레딧의 인게임 검수가 남아 있다. 자동 검사 통과를 전 구간 플레이 검수 완료로 간주하지 않는다. 배포 메타데이터는 `releaseReady=false`다.
