# 변경 기록

## 0.1.0-beta.3 — 2026-10-20

- 1,838개 원문·한국어 전체를 1차 대조하고 beta.2 대비 164개 문구 교정.
- 버널의 구어체, 설명 대사의 주어·대상, 관용구·농담·감정 표현과 대화 연결 보완.
- 강인도(Poise) 용어 통일, 차지·방어·대시 조건 설명 정돈.
- NPC·퀘스트·아이템·연구 일지와 주요 스토리의 모호한 표현 교정.
- 처빌과 알스트로메리아의 말투 기준 수정. 항목별 수정 사유 및 원문·번역 해시 기록.
- 텍스트 검토 상태와 인게임 검수 상태 구별. 전 구간 플레이 검수는 사용자 진행 중.
- 폰트·data.win·실행 파일은 beta.2와 동일. 날짜 뒤쪽 깨짐은 계속 보류.

## 0.1.0-beta.2 — 2026-10-20

- 사용자 피드백을 반영해 도입부 버널 대사와 초반 선상 대화의 직역투를 재검토.
- 이해하기 어려운 대명사·영어식 관용 표현을 정리하고, 짧고 퉁명스러운 구어체로 수정.
- 비행선 병사들과의 대치, 처빌 첫 만남, 알스트로메리아와 대치 후 대화, 검을 주운 경위 관련 대화의 연결 보완.
- 영어 키·제어 코드·변수 유지. 게임 실행 파일과 폰트 데이터는 beta.1과 동일.
- 릴리즈 버전의 `2023-04-06` 뒤쪽 표시 깨짐은 사용자 요청에 따라 보류.
- 인게임 확인은 사용자가 진행하며 전 구간 검수는 계속 미완료 상태.

## 0.1.0-beta.1 — 2026-10-20

- Steam Build 10939741용 한국어 언어 항목 추가.
- 고유 메시지 1,838개 전체 한국어 초안 작성.
- 본문 한글 11,172자·호환 자모·필요 기호와 크레딧 글리프 보강.
- 변수·제어 코드·JSON 키·글리프 수록 여부 자동 검사.
- 원본 해시 검사, 사전 재구성, 최초 백업 보존, 설치 실패 시 복구, 제거 시 충돌 검사.
- 원본의 중복 키 `Vicious`를 단일 출력 키로 정리.
- 사용자 확인: 초기 시제품의 한국어 선택·표시·재실행 유지 정상.
- 남은 관문: 전체 번역 후보본 전 구간 플레이 및 컨트롤러·배율·크레딧 검수.
