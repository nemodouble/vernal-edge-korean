# 초반 대사 재검토 — beta.2

사용자 피드백: 버널의 대사가 어색하고 이해하기 어렵다는 사용자 피드백.

총 50개 대사를 수정했다. 버널 대사 37개와 대화 연결에 필요한 주변 인물 대사를 포함한다.

## 교정 기준

- 말로 읽었을 때 자연스러운 짧은 반말을 사용한다.
- 원문 관용구의 뜻과 인물의 의도를 우선하고, 문장 구조를 그대로 따라가지 않는다.
- 무엇을 가리키는지 혼란스러우면 인물·물건을 명시한다.
- 버널의 도발과 무뚝뚝함을 살리고 사건·관계·정보는 새로 추가하지 않는다.
- 영어 키, 버튼·연출 제어 코드, 치환 변수는 보존한다.
